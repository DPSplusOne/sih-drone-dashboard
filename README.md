# Aegis Nexus — SIH Drone Command Center

A responsive frontend concept for a drone digital-twin and command-and-control platform.

The dashboard represents the project workflow in the supplied brief:

1. Digital-twin environment
2. Drone flight simulation
3. RF signal synthesis and labeled datasets
4. AI model training and command-and-control deployment
5. Scientific validation against reference telemetry


## Included interactions

- New-mission feedback
- Drone selection updates the active telemetry label
- Map / terrain layer toggle
- Model deployment feedback
- Responsive layouts for desktop and mobile
